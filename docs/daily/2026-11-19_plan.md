**모델별 예상 비용 (요금 기준일 2026-11-03, Anthropic 공식 API 요금)**

가정: 분석 1회에 입력 8,000 토큰, 출력 4,000 토큰(사고 토큰 포함). 실제 값은 작업 6에서 측정해 D3 보고서에 적는다. 캐시 할인과 배치 할인은 반영하지 않았다.

| 모델 | 입력 / 출력 (100만 토큰당) | 분석 1회 | 120회 (12사례 × A·B × 5라운드) |
|---|---|---|---|
| `claude-opus-5-5` | $4.00 / $20.00 | 약 $0.11 | 약 $13.4 |
| `claude-sonnet-5-5` | $2.00 / $10.00 | 약 $0.056 | 약 $6.7 |
| `claude-haiku-5-5` | $0.10 / $0.50 | 약 $0.003 | 약 $0.34 |

- 2만 원 예산은 환율에 따라 달라지지만, Opus 5.5로 120회를 돌리면 예산 대부분을 쓴다. 방식 C(에이전트)는 호출당 토큰이 더 많다.
- 계획서는 세 방식이 같은 모델 버전을 쓰도록 요구한다. 모델을 중간에 바꾸면 이전 결과와 비교할 수 없으므로 여기서 정한 모델을 평가 끝까지 유지한다.
- 모델 선택은 비용과 품질의 절충이라 대신 정하지 않았다. 답이 없으면 기본값으로 진행한다.

**위험과 대응**

- holdout을 dev와 같은 사람이 같은 날 만들면 결함 유형이 비슷해질 수 있다. 새 모듈에 절반 이상을 두고, dev에 없는 결함 종류(자료형 변환, 정렬·순서, 경계 날짜, 예외 처리 누락)를 쓴다.
- B의 파일 선택 규칙이 정답 파일을 우연히 항상 포함하거나 항상 빠뜨릴 수 있다. dev 12건에서 규칙이 고른 파일과 정답 파일의 포함 여부를 표로 기록하되, 그 결과를 보고 규칙을 고치지 않는다(고치면 사유를 기록).
