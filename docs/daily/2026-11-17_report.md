**계획과 달라진 점**

- **case-004 설계:** 계획서에는 유형만 정했다. "자료만으로 결론 불가"를 실제로 만들기 위해, CI가 `test-data` 릴리스에서 가격표를 내려받게 하고 수집 중에만 가격을 바꿨다. 수집 직후 원본으로 복구했고, 이후 `main` 실행이 통과해 복구를 확인했다.
- **pre-commit 설정 변경:** 공백 정리 훅이 평가 입력 사본(`job.log`, `junit.xml`)을 수정해 원본과 달라지는 문제가 있었다. 해당 훅에서 `evals/cases/`를 제외했고, 사본이 원본과 바이트 단위로 같음을 확인했다.
- **대상 저장소 CI 보완:** 첫 실행에서 Node.js 20 지원 종료 경고와 `ubuntu-latest` 이전 예고가 나왔다. Actions를 최신 주 버전(v7)으로 올리고 러너를 `ubuntu-24.04`로 고정했다. 릴리스 태그 푸시로 CI가 실행되던 문제도 브랜치 푸시만 실행하도록 고쳤다.
- **수집은 수동:** 입력 묶음은 `gh` 명령으로 수동 수집했다. 같은 형식의 수집기는 F01로 D2에 구현한다.

**확인이 필요한 사항**

- uv의 Python 설치 중 `Missing expected target directory for Python minor version link` 오류가 났다. Python 3.12.16 자체는 정상 설치·동작했고 프로젝트 가상환경도 만들어졌다. 실행에는 영향이 없어 그대로 두었다.
- 이 세션에서는 새로 설치한 `uv`, `gh`가 PATH에 잡히지 않아 전체 경로로 실행했다. 새 터미널에서는 정상일 것으로 예상한다.
