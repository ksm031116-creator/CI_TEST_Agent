**위험과 대응**

- 방식 C가 정답이나 이후 수정 커밋을 읽으면 평가가 무의미해진다. 조회 도구가 스냅샷 폴더 밖 경로를 거부하도록 만들고, 경로 조작(`..`, 절대 경로, 심볼릭 링크)을 테스트한다.
- 에이전트는 호출 횟수가 정해져 있지 않아 비용이 튈 수 있다. 실행당 한도를 코드로 강제하고, 모든 호출은 지금처럼 사용량 장부를 거친다.
- 사람 검토가 없으면 결과표가 계속 "미검토"로 남는다. 최종 평가 전까지 검토가 없으면 그 사실을 결과에 명시한다.
- dev 사례를 여러 번 보면서 설계하면 dev에 맞춰질 수 있다. 방식 C의 프롬프트는 방식 A/B의 v0를 바탕으로 도구 사용 설명만 더하고, dev 결과를 보고 고친 내용은 문서에 날짜와 사유를 남긴다.
