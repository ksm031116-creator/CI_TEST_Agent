**계획과 달라진 점**

- **유형별 2개씩이 아니라 3·3·3·2·1로 구성했다.** "자료만으로 결론 불가"는 외부 데이터 변경 외의 방식(시간 의존, 환경 변수)을 실제 CI에서 재현하기 어려웠다. 대신 계획서가 요구하는 "지원 범위 밖 표시"를 검증할 `out_of_scope` 유형을 새로 만들었다(case-012, 의존성 설치 실패).
- **내 실수로 실행 6건이 오염되어 재실행했다.** case-011용으로 테스트 데이터를 바꾸는 시점이 너무 빨라, 먼저 푸시한 case-005~010의 첫 실행이 바뀐 데이터를 내려받았다. 그 결과 무관한 실패가 하나씩 더 들어갔다. 데이터를 복구한 뒤 6건을 재실행해 재실행분(`run_attempt` 2)을 사례로 썼다. 첫 실행의 묶음은 `work/inputs/`에 남아 있고 사례로는 쓰지 않는다. 앞으로 데이터를 바꾸는 사례는 다른 실행이 모두 끝난 뒤에 따로 실행한다.
- **재실행 덕분에 확인된 점:** 같은 실행의 재실행이 `a1`/`a2`로 별도 묶음이 되고 기존 묶음을 덮어쓰지 않는 것을 실제 데이터로 확인했다.
