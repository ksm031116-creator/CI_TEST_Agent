**위험과 대응**

- 실제 CI 실행이 필요한 작업은 GitHub Actions 상태에 따라 지연될 수 있다. 지연되면 로컬 pytest 결과로 사례 형식을 먼저 확정하고, CI 수집은 다음 날로 넘긴다.
- 사례를 의도적으로 만들면 실패가 지나치게 쉬워질 수 있다. 사례마다 유형과 "로그만으로 풀리는지" 예상을 메타데이터에 적어, 난이도 편중을 보고서에서 확인한다.
